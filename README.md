# Grammar

A tool that manages Contex Free languages defined by BNF grammars written in the Swift programming language.



## References

Dick Grune, Ceriel J.H. Jacobs,  
Springer Publishing Company 2008

by Alfred V. Aho, Ravi Sethi, and Jeffrey D. Ullman

Pearson 2009

## Installation
Add this package to your Swift project using the Swift Package Manager.

Add to your Package.swift:  
```swift
dependencies: [
    .package(name: "Grammar", url: "https://github.com/hakkabon/Grammar", from: "0.0.1"),
],
```

Then import:
```
import Grammar
```
